# 🛠️ Projects

## 1. 🔍 Windows Registry Forensic Analyzer (WRFA)

**WRFA (Windows Registry Forensic Analyzer)** is a Python-based forensic tool developed during the internship for collecting and analyzing useful Windows Registry artifacts.

The project includes a web-based dashboard for viewing forensic information and exporting results in different formats.

### 🔹 Main Modules

| Module | Purpose |
|---|---|
| 🖥️ System Information | Windows and host information |
| 📦 Installed Software | Installed application artifacts |
| 🚀 Startup Programs | Startup-related entries |
| 🔌 USB Devices | USB device artifacts |
| 👤 User Activity | Windows user activity artifacts |
| ⌨️ RunMRU | Recently executed commands |
| 📄 Recent Documents | Recently accessed documents |
| 🧩 UserAssist | Application execution activity |
| 📊 Report Export | JSON, CSV and PDF reports |

### 🔹 Features

- 🖥️ System Information collection
- 📦 Installed Software analysis
- 🚀 Startup Programs analysis
- 🔌 USB Device artifact collection
- 👤 User Activity analysis
- 🔎 RunMRU analysis
- 📄 Recent Documents analysis
- 🧩 UserAssist analysis
- 📊 JSON export
- 📑 CSV export
- 📕 PDF forensic reports
- 🌐 Web-based forensic dashboard

### 🔹 Technologies

`Python` `Flask` `Windows Registry` `HTML` `CSS` `JavaScript` `ReportLab` `JSON` `CSV`
